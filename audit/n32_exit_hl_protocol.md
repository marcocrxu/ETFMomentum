# N-32 事前注册：N 日高低点结构离场（卖出侧）

状态：**跑前注册** · 2026-10-30 · 用户提议（"更重要的是出货的位置"）

## 1. 假设

N-30 已否掉"高低点作为**入场**闸门"（触发点本来就在区间底部，信息冗余）。但离场侧不同：
现有退出全是**相对/绝对动量**口径（掉出第一名、20日动量掉出、−5% 止损、加速止盈），
没有一条看**价格结构**（距高点回撤多少、是否破前低）。用户认为"卖点"才是这个因子的用武之地。

## 2. 机制（两个，独立可开关）

| 参数 | 语义 | 触发式 |
|---|---|---|
| `exit_dd_high` | **回撤离场**：现价距 N 日最高点回撤 ≥ X% | `px ≤ HH_N × (1−X%)` |
| `exit_break_low` | **破底离场**：现价跌破前 N 日最低点 | `px < min(px[t−N .. t−1])` |

- 窗口 `exit_hl_win ∈ {60, 120}`（3 个月 / 6 个月）。
- **无前视**：HH 含当日（今天是窗口内最高也允许）；LL **不含当日**（"破前低"必须是与过去比，
  含当日会因 LL ≤ px 恒不触发 —— 这是实现时的关键陷阱）。
- 只作用于**已持仓**，与固定止损 −5%、加速止盈、上证空仓并存，先到先触发；
  抄底锁仓期内**允许**触发（与止损同权限，符合锁仓期"只准离场不准进场"语义）。
- 触发后与止损同路：有更优候选就切过去，没有就清到空仓。
- 默认 `exit_hl_win=0` → 生产基线逐分不变（pytest 钉死）。

## 3. 网格（预固定）

- 回撤离场：win ∈ {60,120} × `exit_dd_high ∈ {5,8,10,15}`
- 破底离场：win ∈ {60,120} × `exit_break_low=True`
- 组合：win ∈ {60,120} × `dd_high=10` + `break_low=True`

共 12 格。面板：六起点 → 2026-08-20，逐起点自比基线。

## 4. 判据（同 N-19/N-29/N-31 四条）

① ≥5/6 起点年化 ≥ 基线 ② 最差起点 ≥ −3.0pp ③ 中位差 ≥ +0.3pp ④ 非孤立尖峰。
全过者再走 lag1_11bp 压力窗（2014-01-02~2026-09-24，延迟一天 + 单边 11bp）不低于基线。

## 5. 事前预期

- 审计已反复证明"我们已有日频的离场机制，再叠一层 = 对同一风险重复收费"（N-9/N-20/N-29：
  移动止损 5~12% 四档全否）。结构离场很可能重蹈覆辙。
- 但 `exit_break_low` 与 trail_stop 有本质差别：trail_stop 锚在**本次入场以来**最高点（对 V 型
  反弹迟钝），破底锚在**滚动 N 日**前低（对慢熊更敏感）。如果这个因子在卖出侧真有用，
  最可能体现在 2018 慢熊 / 2022 阴跌段。
- 预期结论：多数为负；重点是看**破底离场**这一支有没有独立信息。
