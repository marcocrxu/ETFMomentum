## 背景

用户质疑"退出机制是否有问题"。对照主流六类退出（信号反转 / 固定止损 / 移动止损 / 时间退出 /
趋势破坏 / 制度开关），引擎已有 ①信号反转 ②固定止损 ⑤加速止盈 ⑥上证空仓，
**唯独没有主流趋势跟踪的标配：移动止损（Chandelier Exit 的百分比简化版）**。

N-28 的离线诊断（截断持仓段，不重算后续路径）显示：移动止损 3/5/8/10/15% 逐段均值
-0.65 / -0.54 / -0.25 / -0.16 / 0.00pp，全部非正；时间退出、MA20 跌破、Donchian10 跌破同为负。
持有期"最大浮盈→最终收益"的回吐中位仅 **1.39pp**，回吐>10pp 的段只占 2%。
→ 可修的"利润回吐"问题在数据上**不存在**，但既然从未做过正式消融，按流程补一个。

## 机制定义（跑前冻结）

`trail_stop = X`：持仓期间，若**现价 ≤ 本次入场以来最高收盘 × (1 − X%)** → 离场。语义：

- 与固定止损 −5% **并存**（不是替换）：先触发的那个生效
- 出口与止损同路：有更优候选就切过去（`ti`），没有就清到空仓
- 持仓仍是动量第一（无处可切）时也触发 → 清到空仓（补"绝对止损"的同类盲区）
- 抄底锁仓期内允许触发（与止损同权限）
- 入场以来窗口 = `[hs, t]` 的收盘序列，逐日取 max；不看盘中最高价（日线口径）
