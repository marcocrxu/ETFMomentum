# N-41 协议：斜率门移植到同行 v9 —— 检验它是否通用（2026-11-02，用户提议）

## 1. 来由

用户 2026-11-02 提议："记得给同行的策略也加上试一试，这条策略对他有没有效果。"

背景：N-40 在我们自己的三标的池（纳指/黄金/创业）上测试「mom20 斜率门」，
发现机制真实（连续 3 天斜率转负确实有效）但参数落在孤立尖峰上（persist 1→8 只有 3 存活）。

**本轮不重复 N-40 的参数搜索**，只回答一个更根本的问题：

> **斜率门是「通用 alpha」，还是只对我们这个三标的小池有效？**

如果在她 11 标的、含 A 股宽基/红利/有色/港股的大池上也有效，说明它是一个**普适的动量质量信号**，
值得投入把它做成稳健版本；如果只在我们的小池有效，则很可能是小池特有的样本拟合。

## 2. 实现（默认关 = 她原策略逐分不变）

在 `backtest/v9_official/strategy.py` 新增：

| 变量 | 含义 |
|---|---|
| `SLOPE_GATE_ON` | 总开关 |
| `SLOPE_GATE_CODES` | 受限标的代码集合；`None`=全部持仓标的 |
| `SLOPE_GATE_WIN` | `slope = mom20(t) − mom20(t−win)` |
| `SLOPE_GATE_MOM_MIN` | 仅当 `mom20 ≥ 此值` 才生效（比例口径，0.02=2%） |
| `SLOPE_GATE_PERSIST` | 斜率须连续 N 天为负才离场 |

在她自己的 `indicators()` 里用 `closes` 计算（她的 `mom20 = closes[-1]/closes[-21]-1`），
结论写入 `ind["slope_hit"]`；`_exit_hit(ind)` 命中时返回离场原因；
`decide()` 里按 `SLOPE_GATE_CODES` 过滤——**只影响离场，不影响选谁/进场**。

已复验：默认全关时她 2016-01 起点结果 **逐位不变**（+4467.4% / +42.6% / −27.0% / 206 次）。
