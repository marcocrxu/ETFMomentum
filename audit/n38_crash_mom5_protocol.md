# N-38 协议：恐慌抄底加入「5 日跌幅」门（2026-11-02，用户提议）

## 背景
同行 V12-R2 的抄底是 **MOM5 ≤ −8% 且 距 MA250 < −20%**（绝对百分比，不按波动归一）。
用户提出把「5 日跌幅」也放进我们的恐慌抄底。
我方现状（`strategy/signal.py::_make_crash_eval`）：
`指数10日动量 < μ−2.5σ`（全历史滚动均值/标准差）且 `指数收盘 < MA200`。

**两者不可直接比较**：我方是「统计相对 z 值 + 年线」，同行是「固定百分比 + 年线」。
本协议把 5 日跌幅设计成三种**互斥**接入方式，分别检验，不混在一起看。

## 三种接入（每组独立消融，基线零变化）
- **A 增量门（AND）**：原触发条件不变，再 AND 一条 `指数 MOM5 <= X%`。X ∈ {−6, −8, −10, −12}
  - 假设：5 日跌幅能过滤掉「慢跌」型假恐慌，只留急跌。
- **B 替代门（替换 mom10 条件）**：`指数 MOM5 <= X%` 且 `收盘 < MA200`，X ∈ {−6, −8, −10, −12}
  - 假设：5 日跌幅比 10 日 z 值更快捕捉「急跌」。
- **C 按波动归一（z 化）**：`MOM5 <= σ5 的 z 值门槛` AND `收盘 < MA200`，z ∈ {−1.5, −2.0, −2.5}
  - 这是对 A/B「固定百分比不按波动缩放」这一缺陷的修正版。
  - σ5 用**当日之前**的 5 日收益率滚动样本标准差（无前视；与 `calc_threshold` 同口径）。

三层都额外记录：**抄底触发次数**、**新增/丢失的触发日**，不只看收益。

## 固定口径
- 数据：`/home/ecs-user/backtest/cache/etf_momentum`（Tushare 原始价 + adj_factor）
- 池：纳指/黄金/创业（BASE_UNIVERSE），Top-1
- 主窗：`2016-07-07 → 2026-10-29`；压力窗：`2016-01-01` / `2018-01-01` 起同终点
- 基线 = 全默认参数（持仓/止损/确认天数等一律不动）
- 判定：年化、回撤、Calmar 三者同时不劣于基线才算「改善」；只看年化提升不算

## 事前判据（防事后挑）
1. **参数必须整条带同向**：任何一档单独好、邻档反向 → 视为噪声，不立项。
2. **触发次数不许塌缩**：若某档抄底次数 < 基线 × 0.5，说明门太紧，即使收益好也不可用。
3. **压力窗一致性**：主窗最好的档，必须在 2016-01-01 / 2018-01-01 两个起点也不劣于各自基线。
4. 结论写进 `audit/审计结果清单.md`，禁止在协议外追加参数再挑。

## 已知局限
- 抄底目标只有「创业」，5 日跌幅门作用在**创业板指/上证指数**上，不是 ETF 自身。
- 我方抄底是「叠加/换仓」语义（`crash_alloc`），与同行「全仓切换」不同。
- 回测收盘口径，未模拟 14:50 实盘价差。
