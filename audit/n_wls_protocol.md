## 1. 为什么测这个

N-11 收益归因显示：在**共同的 3 只标的**上我方反而比她多赚 0.90 对数；她的全部超额（+1.104）
来自池外 8 只标的，而她能在这些标的上赚 28~59bp/天，我方 mom20 排名只有 3~6bp/天。
→ **两边真正的能力差在排名器，不在标的池。** 这是唯一有归因证据支撑的可移植方向。

## 2. 待测机制（严格按对方口径，非我方现有 risk_adj_mom）

对方 `strategy.py:279-320` 的 SCORE_WLS：

```
对最近 window 个收盘做时间加权最小二乘，权重 w_i = i+1（越近越大）
sl   = (Σw(x-x̄)(y-ȳ) / Σw(x-x̄)²) / ȳ        # 除以加权均价 → 百分比/日
slope_ann = sl × 250
smooth > 1 时：slope_ann = mean(对位移 k=1..smooth 的同样回归)   # 近 N 个报价的分数均值
score = slope_ann / vol20                      # vol20 = 日收益标准差(小数)
```

**与已否决的 `risk_adj_mom` 的区别**：那是「20 日价差动量 ÷ vol20」，分子是端点差值；
WLS 分子是**回归斜率**（抗端点毛刺、对路径形状敏感），且带多报价平滑。二者不可互相推断，
故独立重测。**排名分只影响选谁，所有阈值（min_gap / 入场 / 离场 / 上证比较）仍用原始 mom20。**
