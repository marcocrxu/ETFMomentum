# N-30 事前注册：恐慌抄底 + 近 N 日高低点结构门

状态：**跑前注册**（本文件先落盘，再写代码/跑数）
日期：2026-10-30
提出人：用户（"把过去三个月、过去6个月的最高点和最低点作为参数加入抄底策略"）

## 1. 要解决的问题

现有恐慌抄底只在**指数动量**维度判定：

```
恐慌抄底 = (指数 mom10 < μ − 2.5σ) 且 (指数 < MA200)
```

它不知道价格在近端结构中的**位置**：同样是 mom10 破线，可能是刚从三个月高点
跌下来的第一波（接飞刀），也可能是贴着 N 日最低点横了半个月（底部）。用户想用
「近 3 个月 / 近 6 个月的最高点、最低点」把这一维补上。

**注意**：这只是追加一个**闸门（filter）**，不改变抄底目标、锁仓期、费用口径。
闸门是单调的：只会让触发**变少**，不会变多——所以本实验的核心问题是
"少掉的那几笔抄底，是不是坏笔"。

## 2. 三个可参数化的机制（各自独立测，不组合先）

窗口 `win`：60 交易日 ≈ 3 个月，120 交易日 ≈ 6 个月（与项目其它窗口口径一致）。

| 参数 | 语义 | 触发额外要求 |
|---|---|---|
| `crash_dd_min` | **深度门**：距窗口最高点的回撤 | `px/HH − 1 ≤ −crash_dd_min%` |
| `crash_pos_max` | **位置门**：收盘价在 [LL, HH] 区间内的分位 | `(px−LL)/(HH−LL) ≤ crash_pos_max` |
| `crash_off_low_max` | **离底门**：距窗口最低点的涨幅 | `px/LL − 1 ≤ crash_off_low_max%` |

- `HH/LL` = 截至**当日收盘**（含当日）的窗口最高/最低价；与 mom10 / MA200 同口径
  （决策日收盘可得的信息，无前视）。
- 闸门判定在**触发的那个指数自身上**做（上证触发就用上证的 HH/LL，创业触发就用
  创业板指的），不跨指数套用。
- 窗口含 NaN 空洞时按"截至当日最后 win 个有效报价"回填（同 `_rolling_mean_valid` 口径）；
  仍不足 win 个有效报价 → 记 `CRASH_DIAG`，按"无法判定"处理（不触发，与三态语义一致）。
- 默认值 `crash_hl_win=0`（关闭）→ 生产基线**逐分不变**，由 pytest 钉死。

## 3. 网格（预先固定，跑完不许加格）

- 深度门：`win ∈ {60,120}` × `crash_dd_min ∈ {5,10,15,20}`
- 位置门：`win ∈ {60,120}` × `crash_pos_max ∈ {0.2,0.3,0.4,0.5}`
- 离底门：`win ∈ {60,120}` × `crash_off_low_max ∈ {3,5,8}`

合计 22 个变体，全部与生产默认（闸门关闭）对比。

## 4. 面板与指标

- **六起点**（与 N-19/N-29 同口径）：2014-01-02 / 2016-01-04 / 2018-01-02 /
  2020-01-02 / 2022-01-04 / 2024-01-02，终点 2026-08-20；每个起点**自比基线**。
- 指标：年化、最大回撤、Calmar、交易笔数、**抄底笔数与逐笔盈亏**（闸门只动抄底，
  抄底账本的变化是主要证据）。
- 样本量警告：默认窗抄底仅 8~10 笔，删 1~2 笔就能改写年化 → 单点差异不构成证据，
  必须过下面的门槛。

## 5. 晋升判据（四条全过才算候选）

1. **≥5/6 起点年化 ≥ 基线**（逐起点自比）；
2. **无灾难起点**：最差起点 ≥ −3.0pp；
3. **中位差 ≥ +0.3pp**；
4. **不是孤立尖峰**：不允许"只有 1 个起点正贡献、其余全负"。

任一变体四条全过 → 记为候选，**仍需**在 lag1_11bp 压力窗（2014-01-02~2026-09-24，
执行延迟一天 + 单边 11bp 滑点）不低于基线，才可进入下一轮。

## 6. 事前预期（写下来防止事后讲故事）

- 抄底只有 8~10 笔，且审计 E8/E9 已证"抄底收益 ≈ 恐慌反弹 beta，入场日踩在局部底部"。
  换句话说**现有触发点本来就在底部附近**，位置类闸门大概率**删掉的是好笔**（V 型反弹），
  年化大概率下降。
- 若出现"某变体六起点全胜"，优先怀疑：① 该变体实际上没删几笔（≈基线，差异是噪声）；
  ② 2015/2016 段被删掉一次大亏（尾部改善），需看逐笔账本再判。
- 因此本实验的**先验结论是"多数变体为负优化"**，真正的价值在于量化"结构维到底有没有信息"。
