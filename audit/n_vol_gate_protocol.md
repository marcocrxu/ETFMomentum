**注册时间：2026-10-22（跑任何一格之前写下；之后不放宽、不追加、不换门槛）**

## 背景：这个候选是怎么活下来的

用户问"能不能多加因子"，先做了三个候选的体检（正交性 / 分组单调性 / 决策改变率）：

| 候选 | 与 mom20 秩相关 | IC（纳指） | 判定 |
|---|---|---|---|
| 短期反转 mom5 | +0.41~+0.48 | +0.006 | 否决（IC≈0 却改 22% 决策） |
| 相关性 regime | — | — | 否决（高相关时动量边际反而最高 5.27pp） |
| **纳指量比 VOL20/VOL120** | **-0.11 ~ +0.12** | **-0.213** | **进消融** |

纳指量比的探索性证据（**全部样本内，不构成结论**）：

- 时序五分组未来 20 日：Q1 **+3.3%** → Q5 **-0.0%**，单调性 **-0.90**
- 分两段：2016-21 IC **-0.213** / 2021-26 IC **-0.214**（一致）；黄金/创业**符号翻转**（噪声）
- 控制溢价档（QQQ-CNY 偏离）后仍成立：放量组 -0.51 / -0.12 / -1.06 vs 缩量组 +2.71 / +3.54 / +2.19
- 控制波动档后仍成立：低波 0.64 vs 3.32 / 中波 1.44 vs 3.08 / 高波 -2.43 vs 1.36
- 引擎逐笔：纳指买入 62 笔，入场量比三分位 胜率 76.2% / 65.0% / 52.4%，平均 +5.30% / +1.03% / +0.99%

## 机制定义（跑前冻结）

`nz_vol_gate = X`：当 513100（纳指ETF）的 **量比 = VOL20均值 / VOL120均值 > X** 时，
**禁止新买纳指**。语义边界：

- 拦的入口：① 空仓入场（含 >3%即买 / 确认买入）② 从上证空仓豁免池买入 ③ 主动切换/快速通道切进纳指
- **不拦**：卖出纳指、止损、加速止盈、上证空仓、切到其它标的
- 止损/急跌发生在当日且目标恰是被门挡住的纳指时 → **落空仓**（不新建纳指仓）
- 恐慌抄底目标恒为创业，不受影响
- 已有纳指持仓**不会**因为这个门被强制卖出（这就是"入场门"而非"状态门"的意义）
