🛠 改进建议（按优先级）

1. 用"每标的绝对动量 + 防御资产"替代"上证空仓" P0
GEM/DAA/VAA 的核心思想：不是用某个外部指数当总开关，而是每个标的自己带趋势过滤——自身动量为负就不持有它，即使它是池里相对最强。 然后不是空仓吃 0 收益，而是切到防御资产（黄金、红利低波、债券 ETF）。 普跌行情里，空仓只能保命，切防御资产还能赚钱。
落地：signal.py 增加 per-asset 绝对动量判断；防御标的设为目标资产而非 -1 空仓。改动量中等，预期收益最大。
2. 动量排名除以波动率（Sharpe 动量） P0
VAA 的做法：score = 动量 / 波动率。裸 20 日涨幅排名天然偏好高波动标的（创业永远比红利低波排名高），换成风险调整后能明显降低回撤。
落地：score = mom20 / std(日收益, 20)，一行代码。建议先做这个验证效果。
3. Top-K 持仓替代 Top-1 P1
DAA 持 Top-3 等权、VAA 持 Top-4。只持 1 只要吃单标的黑天鹅和全部切换冲击；Top-2/Top-3 等权通常回撤显著下降、Calmar 上升，代价是收益略降。
落地：signal.py 的 pos 从单个 int 改为权重 dict，架构改动较大。
4. 多周期动量组合 P1
单一 20 日周期很脆弱，换参数结果就变。经典做法是 1/3/6/12 月多周期加权或投票，降低对单一参数的敏感度。
落地：score = 0.5×mom20 + 0.3×mom60 + 0.2×mom120，改动小。
5. 动量崩溃防护系统化 P2
恐慌抄底本质上是一种崩溃应对，但它是左侧加仓。经典防护（Daniel & Moskowitz）：深跌后波动率飙升 + 急反弹时，弱资产反弹最猛，按相对动量追进去容易接飞刀——此 regime 下应临时切防御或暂停轮动。
落地：检测"市场 N 日回撤超 X% + 波动率骤升"，触发后冻结切换 M 天。
6. 高波动标的仓位上限 P2
创业/科创50 这类高波动标的设仓位上限（如 70%），其余放防御资产。简版波动率目标，拉平各标的风险贡献。
落地：买入时按标的波动率分档限制仓位。
7. 动量质量做 tie-breaker（frog in the pan） P2
动量接近时，选"上涨路径平滑"的（上涨天数占比高、单日涨幅均匀），而不是"几根大阳线拉出来"的。平滑动量持续性更好。
落地：动量差小于阈值时，比较 20 日内上涨天数占比。

建议落地顺序：#2（一行代码）→ #1（中等改动、预期收益最大）→ #3（架构改动）→ #4 → #5/#6/#7。每个都以 ablation 开关形式加入，逐一对比十年回测。
