# 科创50 扩池/换池实验记录（2026-08-23，全部否决）

**触发**：近一年（2025-08-21 ~ 2026-08-21）4池(+科创50) 大幅跑输主策略，用户要求尝试优化。
**结论**：扩池、修复、换池三条路线 12+ 个方案全部失败；实验加固 F4「禁止扩池」纪律。主策略池与参数**保持不动**。
**存档**：审计清单 I-18 + I-18 补；本文件为完整数据留档。

## 1. 基线对比：主策略 vs 4池（近一年）

| | 3池 主策略 | 4池 +科创50 |
|---|---|---|
| 累计收益 | **+58.2%** | +39.9% |
| 最大回撤 | **-15.9%** | -25.3% |
| Calmar / 夏普 | **3.82 / 1.65** | 1.65 / 1.08 |
| 换仓次数 | **32** | 49 |
| 深亏腿(≤-5%) | **2 条** | 6 条 |

科创50 同期单资产 +44.8%（全池最牛），但策略在它身上一年只提取 +9.1pp。
主因：① 阈值错配（-5% 止损在 35~40% 波动资产上成交 -7~-8%，7/2 -7.67%、7/16 -7.32%）；
② 与创业高度相关的噪声切换；③ 路径依赖（多一资产改变全部决策）。

格式：累计% / Calmar。

换池崩盘三因：
1. **588080 于 2020-11-16 才上市**——2016-2020 换池实际退化为纳指+黄金两资产池，丢掉创业 2019-2021 大牛段；
2. **恐慌抄底生态位换不回来**——抄底改指科创50 后更差（2022 两笔 +6.66%/-1.96% vs 创业 +8.2%/+5.6%），科创50 恐慌反弹弹性不如创业；
3. **2023-2026 干净窗口也只剩 42%**（+157 vs +375）——近一年打平是单一 regime 巧合。

## 4. 落定结论

1. 主策略（纳指/黄金/创业 + 现有默认参数）**一切不动**；扩池/换池均否决，F4 纪律新增证据。
2. 想暴露科创50 → 只适合**策略外卫星仓**（独立规则，另行研究），不动主策略。
3. 复现：`PYTHONPATH=. python3 -c "from web.bt_runner import run_backtest; ..."`，参数见上表；引擎研究参数 `crash_target_name` 默认"创业"不改行为。
